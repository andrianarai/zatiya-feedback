# ЗАТІЯ — форма відгуків

Мобільний сайт для анонімного зворотного зв’язку після зустрічей ЗАТІЇ.  
Учасник відкриває посилання або QR-код для своєї зустрічі, оцінює її користь, відповідає на запитання про нові ідеї та за бажанням залишає два текстові коментарі.

## Як це працює

Сторінка розміщена на GitHub Pages. Номер зустрічі передається в посиланні через `?meeting=1` (доступні значення від `1` до `4`). Після надсилання браузер передає відповідь до Google Apps Script, а той записує її в Google Sheets на вкладку `Responses`. Без правильного номера зустрічі форма не відкривається.

## Структура проєкту

- `index.html` — розмітка форми та екрани результату.
- `style.css` — оформлення й адаптація для мобільних пристроїв.
- `script.js` — перевірка полів і відправлення даних.
- `google-apps-script.gs` — серверний код для запису в Google Sheets.

## Налаштування

Для власного розгортання потрібні Google Таблиця, Web App у Google Apps Script та GitHub Pages. У `google-apps-script.gs` задається ID таблиці, а в `script.js` — URL розгорнутого Apps Script із суфіксом `/exec`. Після зміни серверного коду потрібно створити нову версію deployment в Apps Script.
